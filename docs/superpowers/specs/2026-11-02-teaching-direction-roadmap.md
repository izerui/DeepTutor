# 老师带学 + 学生自学：整体设计与改造方案

> 日期：2026-11-02（经一轮独立审查后修订）
> 状态：待确认。确认后按第 13 节分批实施，每批再出详细设计。
> 关联：`2026-10-29-roles-permissions-design.md`（角色、班级、发布范围、练习集）。本文沿用它的规则，冲突处以本文为准。

## 1. 方向与原则

1. **管理员管系统。**
   - 管理模型、账号、班级、学生权限。
   - 可以发布全校都能用的资料，学生那边显示「学校发布」。
   - 对别人发布的内容只兜底：撤回。
   - 看不到任何人的个人数据，也看不到作业的内容。
2. **老师是主力。**
   - 创建内容，带着学生学：布置任务、收作业、批改、点评、发公告，看自己班的学习情况。学生的疑问由 AI（聊天和「小老师」）解答，老师不做答疑（2026-11-02 确认）。
   - 只面对自己任课的班。
   - 老师自己也能学习。
3. **学生两条线并存，界面上始终分开。**
   - 老师带着学：完成老师布置的任务，使用学校发布的资料。
   - 自己学：想学什么就建什么（精通之路、书、知识库、课程、自己的任务卡片、补练），宽严自己定。默认允许，管理员可以按人或按班关掉。
4. **数据各归各。**
   - 学生的对话、笔记、自建内容、题库只属于本人。
   - 老师只看得到三样：学生在自己发布的内容上的成绩和进度；交给自己的作业；学生自学部分的统计数字（时长、掌握数），看不到内容。
5. **发布时就选好发给谁。** 有任课班时默认预选这些班，没有就必须自己选；「全部」只有主动选才用。
6. **任何变化都有去处。** 账号、班级、内容发生任何变化，相关的任务、作业、公告、点评、通知、报告、课程都有明确的处理（第 6 节逐条列出）。

## 2. 三种角色能做什么

| 能力 | 管理员 | 老师 | 学生 |
|---|---|---|---|
| 系统配置、账号、学生权限 | ✓ | | |
| 建班、管班 | ✓（所有班） | ✓（自己任课的班，可邀请其他老师一起任课） | |
| 进班、退班 | | | ✓ |
| 发布书、知识库、精通之路、练习集、课程 | ✓（学校发布） | ✓ | |
| 布置任务 | ✓（学校发布；不能带作业） | ✓ | |
| 收作业、批改、点评 | | ✓（自己布置的） | |
| 发班级公告 | ✓（任何班） | ✓（自己任课的班） | |
| 看班级报告 | | ✓（自己任课的班） | |
| 重置密码 | ✓（任何人） | ✓（只限本班学生） | 自己改自己的 |
| 自己学习、自建内容 | ✓ | ✓ | ✓（管理员可按人、按班关掉某几项） |
| 对别人发布的内容 | 只能撤回 | 只读（别人发给自己的） | 只读 |

## 3. 来源与可见性

### 3.1 三种来源

| 来源 | 显示 | 判定 | 接收者能做什么 |
|---|---|---|---|
| 学校发布 | 「学校发布」 | 发布者当前是管理员 | 学习、使用；不能改 |
| 老师布置 | 「老师布置 · 张老师」（老师之间互相发的显示「张老师分享」） | 发布者当前是老师 | 学习、作答、提交；不能改 |
| 别人分享 | 「张三分享」 | 发布者当前是学生（只有旧数据里学生公开过的书、知识库会这样） | 只读 |
| 我自己的 | 「我自己的」 | 自己创建 | 全部操作 |

- 判定只在后端做一处：所有列表接口的每一项都带 `source: {kind, name}`。
- 发布者角色变了，来源标签跟着变。老师被删除或改成学生时，内容会先转交给别人（第 6.1 节），标签随新的所有者变化。
- 前端统一用一个来源标签组件和一个「按来源分组」工具。
- 用到的地方：首页、精通之路、书、知识库、课程、练习集、任务、任务看板、题库和错题（每道题标出处：哪个练习集、哪条精通之路、哪个任务，或者自己练的）。
- 现状：各处叫法不一，也不区分老师和管理员（待做）。

### 3.2 谁能看到什么

| 东西 | 学生本人 | 布置它的老师 | 同班其他老师 | 管理员 |
|---|---|---|---|---|
| 对话、笔记、自建内容、题库 | ✓ | | | |
| 自学的统计数字 | ✓ | ✓（自己班的学生） | ✓（自己班的学生） | |
| 在某位老师内容上的成绩、进度 | ✓ | ✓ | 只看得到发了什么，看不到成绩 | |
| 作业原文、附件、分数、评语 | ✓ | ✓ | | |
| 班级公告 | 那个班的学生 | ✓ | ✓ | ✓ |
| 老师点评 | ✓ | ✓（写点评的那位） | | |

## 4. 发布范围的统一规则

适用于：书、知识库、精通之路、练习集、课程、任务。

1. **第一次发布时必须选好发给谁。**
   - 有任课班：默认预选这些班，可以改。
   - 没有任课班（包括管理员）：不给默认值，必须自己选。
   - 「全部」只有发布者主动选才用。

   选好才算发布成功。中间不会有「对所有人公开」或「谁也看不到」的空档。
2. **可选的对象。**
   - 书、知识库：班、学生、老师都可以选。
   - 精通之路、练习集、课程、任务：只能选班和学生，它们是给学生学的。
   - 带作业的任务：不能选「全部」，只能选自己的班和自己班上的学生。
   - 老师只能选自己任课的班和这些班上的学生，以及任何老师；管理员可以选任何班、学生和老师。都不能选管理员。
3. **收窄范围。** 会让人失去访问时，先显示人数，确认后才保存（已有）。
4. **只有发布者能改范围。** 管理员对别人的内容只能撤回。
5. **范围随班级实时变化。** 进班的学生自动收到；退班、被移出、班级归档后，只靠这个班收到的就失去了（已有）。
6. **引用的内容要覆盖接收者。**
   - 任务、课程引用的精通之路、练习集、书、知识库，它们的范围必须覆盖任务或课程的全部接收者，否则不让发布，并指出是哪一项、缺了谁。
   - 精通之路引用的书和知识库，有接收者用不了时，发布前提醒，不拦（待做，第 9 节第 4 条）。
   - 发布者自己的私有资料，接收者经发布的内容可以用，但打不开资料本身（D8，已有）。
7. **范围数据丢失时一律不放行**，恢复备份后才能继续发布（已有）。

## 5. 各项功能的完整流程

### 5.1 账号与入驻

- 老师账号只能由管理员创建（已有）。
- 学生账号：
  - 公开注册打开时可以自己注册，关闭时只能用邀请链接注册，也可以由管理员创建（已有）。
  - 带邀请链接注册的，直接进班（已有）。
  - 同一来源短时间内的注册次数有上限（待做）。
- 忘记密码：管理员可以重置任何人的，老师只能重置本班学生的。重置或自己改密码后，其他地方的登录全部失效（已有）。
- 第一个管理员不能删除，角色不能改（已有）。他的密码可以由其他管理员重置（待做，现在只有他本人能改）。
- 停用账号：不能登录；只靠班级收到的内容暂时失去。重新启用后自动恢复，学习记录不丢（已有）。

### 5.2 班级

- **建班**：管理员可以建任何班；老师建的班，老师自己就是任课老师（已有）。
- **任课老师**：
  - 一个班可以有多位任课老师。老师可以邀请其他老师一起任课（已有）。
  - 老师只能自己卸任，而且卸任后班里不能一个老师都没有（已有）。
  - 管理员可以随意调整任课老师，班里可以没有老师（已有）。
- **进班**（已有）：
  - 邀请链接或二维码，重新生成后旧链接失效；
  - 老师发邀请，学生接受；
  - 管理员直接分班；
  - 已归档的班不能再进人。
- **出班**：学生自己退班，或被老师、管理员移出（已有）。
- **归档**：学期结束时归档。邀请链接和未接受的邀请作废；只靠这个班收到的内容和任务，都变成「已关闭」（见 5.4，学生仍能在「历史」里看到自己的结果）。可以恢复，恢复后一切回来（已有）。
- **班级报告**：只有任课老师能看，只看数字（已有）。

### 5.3 共享内容（书、知识库、精通之路、练习集、课程）

状态：**草稿 → 已发布 → 已撤回**。

| 动作 | 结果 |
|---|---|
| 发布 | 按第 4 节选范围，接收者收到通知 |
| 改版后再发布 | 接收者下次打开时换成新版；已经交过的作答保留，并记下当时的版本（已有） |
| 收窄范围 | 确认人数后保存。失去访问的人，相关任务变「已关闭」；他们已有的成绩、作业保留在老师那边，标「不在范围内」 |
| 撤回 | 书、知识库改为私有；精通之路、练习集、课程改为已归档。接收者不能再进入，相关任务变「已关闭」，老师那边保留成绩和作业 |
| 删除 | 只有作者能删，而且只能删从没发布过的。发布过的只能撤回（练习集已经是这样，其他内容统一按这条） |
| 管理员兜底 | 对别人的内容，管理员点「删除」时执行的是撤回（书、知识库已有；精通之路已有；练习集、课程、任务待做），不能改内容、不能改范围 |

### 5.4 任务

**内容**：标题、说明、截止时间（可选）、开放时间（可选）、发给谁，以及要做的事。要做的事有五类：

- 学一条精通之路：可以设达到多少比例算完成，默认全部掌握。
- 做一个练习集。
- 读一本书的某几章。
- 交一份作业（见 5.5），管理员布置的任务不能带作业。
- 纯说明，比如「周五前复习第三章」，由学生自己标完成。

**不重复**：

- 同一个学生、同一个任务只算一条，不管他是通过哪个班、还是被单独点名收到的。
- 老师发出的练习集和精通之路，在学生那边自动显示为任务；练习集的截止时间就是任务的截止时间。
- 一项内容一旦被某个任务引用，就不再自动生成任务，避免一件事出现两次。

**老师那边**：草稿 → 已发布 → 已撤回；删除只能删从没发布过的（同 5.3）。

**学生那边的状态**：

| 状态 | 什么时候 | 怎么离开 |
|---|---|---|
| 未开放 | 开放时间还没到。日历上显示「X 日开放」，看不到内容 | 到了开放时间，变「待完成」 |
| 待完成 | 已开放，还没完成 | 完成后变「已完成」；过了截止时间变「逾期未完成」 |
| 逾期未完成 | 过了截止时间，还没完成。仍然可以做、可以交 | 完成后变「已完成」，并标「逾期」 |
| 已完成 | 系统自动判定：练习集交过卷；精通之路达到比例；读书打开过指定章节；作业交了且没被退回。纯说明的任务由学生手动标，老师那边显示「学生自报」 | 一直保留，不会因为内容改版、档位调整而撤销 |
| 已关闭 | 任务被撤回、学生离开了范围、班级归档，或者引用的内容被撤回 | 重新回到范围（再进班、范围放宽、班级恢复）就回到之前的状态 |

**规则**：

- 「已关闭」不是存下来的，是按学生当前是否在范围内实时算出来的；「已完成」是存下来的，永久有效。
- 已关闭的任务放在学生的「历史」里，只读。学生能看到自己的成绩、作业、评语，但不能再进入内容。
- 老师可以改说明、范围和截止时间。截止时间改了，学生那边按新时间重算，并收到通知。
- 练习集选了「截止后显示答案」时，答案一旦显示过，截止时间就不能再往后改。
- 完成情况由系统算，老师和学生都不能手改（纯说明的任务除外）。

### 5.5 作业

**状态**：

| 状态 | 什么时候 | 学生能做 | 老师能做 |
|---|---|---|---|
| 未交 | 任务已开放，还没交 | 交 | — |
| 待批改 | 交了（截止前可以重交，以最后一次为准） | 截止前可以重交 | 批改、退回 |
| 已退回 | 老师写明原因退回，任务回到「待完成」 | 重交，逾期与否按重交的时间算 | — |
| 已批改 | 老师确认了分数和评语 | 查看 | 修改分数和评语 |

- 交的内容：文字，加图片或文件，数量和大小有上限。
- AI 建议：学生交上来后，AI 按老师写的评分要点（可选）给建议分和简短评语，只有老师能看到，不算在学生的 AI 用量里。AI 出错或用不了时就没有建议分，不影响批改。
- 批改：老师确认或修改分数，写评语，可以批量批改。批改或退回时，学生收到通知。
- 谁能看：只有学生本人和这个任务的老师。
- 班级归档或学生离开范围时：
  - 已交的作业照样由老师批改；
  - 处于「已退回」的，按最后一次提交算「待批改」；
  - 学生不能再交。
- 附件放在系统数据目录下，按任务分文件夹，下载时检查身份。作业被删除时（学生账号删除、或任务被删除）附件一起删。

### 5.6 老师点评

- 老师可以点评三样东西：
  - 作业（批改时的评语就是点评）；
  - 学生的某次练习作答；
  - 学生在自己发布的精通之路上卡住的知识点。
- 只有这个学生和写点评的老师能看到。学生在对应位置看到，并收到通知。
- 老师可以修改或删除自己的点评。

### 5.7 班级公告

- 老师给自己任课的班发，管理员给任何班发。可以置顶。
- 只有作者和管理员能修改、删除。作者卸任或账号被删后，公告保留，只读，管理员可以删。
- 学生在首页和通知里看到。班级归档后，学生看不到这个班的公告了（和其他内容一致）；班级恢复后又能看到。

### 5.8 通知

- 只做站内通知：右上角铃铛，有未读数。不接微信，也不接邮件。
- 同一件事只发一条：
  - 设了开放时间的任务，只在开放时通知；
  - 「新任务」和「新内容」不重复发；
  - 截止前 24 小时的提醒，只发给还没完成的人。
- **学生会收到**：
  - 新任务或新内容；
  - 任务开放、截止提醒、截止时间被修改；
  - 作业已批改、作业被退回；
  - 老师点评；
  - 班级公告；
  - 进班邀请。
- **老师会收到**：
  - 新交的作业（按任务汇总成一条）；
  - 自己内容引用的资料被资料主人撤回；
  - 别人的内容转交给了自己（第 6.1 节）。
- 点开通知时会重新检查权限。东西已经撤回、或者自己已经不在范围内的，显示「内容已不可用」。
- 通知保留 90 天，可以全部标为已读。账号删除时，他的通知一起删除。

### 5.9 补练

- **老师**：在班级报告里选出错得多的知识点或题目，一键生成补练练习集，发给全班或其中几个学生，同时生成任务，之后按 5.3、5.4 走。
- **学生**：从自己的错题一键生成补练，算「我自己的」，老师看不到，不算任务。

### 5.10 课程

- **老师的课程**：
  - 把精通之路、书、练习集、任务按顺序打包成一门课，发给班级，走 5.3 的流程。
  - 顺序只是建议，不上锁。某一项被撤回，后面的照样能学。
  - 课程里每一项可以设开放时间。只对「只经这门课收到」的内容有效；同一项如果也单独发给了学生，以单独发的为准。
  - 学生在课程列表的「老师布置」一组里看到，只读。
- **学生自己的课程**：
  - 照旧能建、能改。
  - 可以把老师课程里的内容加进来，只是引用、不复制。
  - 凡是本人已经打不开的那一项（被撤回、自己退了班、范围收窄了），都显示「已不可用」。
- **课程和里面的东西各管各的**：课程撤回了，里面单独发过的任务照常有效。

### 5.11 学生自学

- 学生可以自建：精通之路、书、知识库、课程、自己的任务卡片、补练。默认都允许。
- 管理员可以按人或按班关掉某一项。合并规则：个人设置优先；没有个人设置的，看所在的班，任一班允许就允许；都没设就用默认（已有三项，其余待做）。
- 关掉以后，已经建的还在，只是不能再新建。
- 自建的东西只有本人能看，不能分享给同学。老师的报告里只有统计数字。
- 精通之路的宽严档位，自建的由自己定（已有）。

### 5.12 首页、工作台、看板、日历

- **学生首页**：
  - 「老师布置的」：待完成和快到期的任务，按截止时间排，以及最新公告；
  - 「学校发布的」：新内容；
  - 「我自己在学的」：最近的自建精通之路和课程；
  - 「历史」入口：已关闭和已完成的任务；
  - 页面上保留聊天入口。
- **老师首页（工作台）**：
  - 我的班；
  - 待批改的作业；
  - 我发出去的内容和完成率；
  - 需要关注的学生：7 天没学、有逾期、错题明显增多、某个知识点卡了很久；
  - 下面是老师自己的学习区。
- **管理员首页**：账号、班级、系统的入口，以及自己的学习区。不做全校统计看板。
- **任务看板**：多一列只读的「老师布置」，内容来自任务，不写进学生个人的看板数据。学生自己的卡片照旧。
- **日历**：学生和老师都有，只显示没关闭的任务的开放时间和截止时间。

## 6. 事件联动表

任何一件事发生后，其他东西怎么跟着变。

### 6.1 账号变化

| 事件 | 班级 | 内容和任务 | 作业、点评、公告 | 通知、报告 |
|---|---|---|---|---|
| 学生被改成老师或管理员 | 离开所有作为学生的班（已有） | 他收到的任务全部「已关闭」 | 已交的作业留在老师那边；点评保留，他仍能看 | 不再出现在老师的报告里（已有） |
| 老师被改成学生 | 卸任所有班（已有） | 和下一行「删除老师账号」走同一套转交，在改角色时立即完成（待做，现在内容仍归他） | 同下 | 同下 |
| 删除老师账号 | 卸任所有班（已有） | 他发的内容、任务、课程，转给执行删除的管理员（书、知识库、精通之路、练习集已有；任务、课程待做）。学生那边照常可用，来源变成「学校发布」 | 有作业的任务：转给它所发班级的另一位任课老师（按班级名排第一个）；一个都没有时，转给管理员，作业保持「待批改」，管理员只能撤回。他写的点评保留，署名「已离任老师」。公告保留，只读 | 收到转交的人收到通知 |
| 停用账号 | 不变 | 只靠班级收到的暂时失去，重新启用后恢复（已有） | 保留 | 保留 |
| 删除学生账号 | 移出所有班（已有） | — | 作业（含附件）、点评删除 | 通知删除；老师成绩表里不再显示（已有） |
| 改密码、重置密码 | 不变 | 其他登录和换设备登录码全部失效（已有） | 不变 | 不变 |

### 6.2 班级变化

| 事件 | 内容和任务 | 作业 | 公告 |
|---|---|---|---|
| 学生进班 | 自动收到发给这个班的内容和任务（已有） | — | 能看到 |
| 学生退班或被移出 | 只靠这个班收到的变「已关闭」（已有） | 已交的留在老师那边照常批改，不能再交 | 看不到 |
| 老师卸任 | 他发给这个班的照常有效；之后不能再选这个班 | 他照常批改 | 他发的公告保留、只读 |
| 班级归档 | 只靠这个班收到的变「已关闭」（已有） | 同「学生退班」 | 学生看不到；老师只读 |
| 班级恢复 | 回到之前的状态（已有） | 恢复可交 | 恢复 |

### 6.3 内容和任务变化

| 事件 | 学生那边 | 老师那边 |
|---|---|---|
| 改版后再发布 | 下次打开换成新版；进行中的作答按打开时那一版判（已有）；已完成的不撤销 | 成绩表按版本区分（已有） |
| 收窄范围 | 失去访问的人，任务变「已关闭」 | 他们的成绩和作业保留，标「不在范围内」 |
| 撤回 | 不能再进入；任务变「已关闭」；自己课程里那一项显示「已不可用」 | 保留，只读 |
| 删除 | 只能删从没发布过的，学生那边本来就没有 | — |
| 开放时间到 | 变「待完成」，收到通知 | — |
| 截止时间到 | 没完成的变「逾期未完成」，仍可做 | 报告里标逾期 |
| 截止时间被修改 | 按新时间重算，收到通知；答案已显示过的练习集不能往后改 | — |
| 引用的资料被资料主人撤回 | 那一项显示「已不可用」 | 发布者收到通知 |

### 6.4 学生自学

| 事件 | 结果 |
|---|---|
| 管理员关掉某项自建 | 已建的保留，只是不能再新建 |
| 学生删除自建内容 | 直接删除，统计数字跟着变 |
| 学生账号删除 | 自建内容随账号删除；公开过或被引用的，按现有交接规则处理（已有） |

## 9. 先修的 4 条（已确认）

1. 管理员可以重置第一个管理员的密码（符合 D20）；第一个管理员仍然不能删除。
2. 发布范围按第 4 节第 1 条统一：书、知识库、精通之路、练习集，第一次公开时先选范围。
3. 学生写的答案不进系统成绩库。重新打开练习集时，从学生自己的题库里取答案，系统里只留分数和对错。
4. 精通之路引用的书和知识库有接收者用不了时，发布前提醒。

## 10. 定下来的规则

| 编号 | 规则 |
|---|---|
| R1 | 一个班多位老师：能看到彼此发给本班的内容，成绩只看自己发的 |
| R2 | 先不加学科、教研组；老师之间用「发给指定的老师」共享资料。组织上有院系和年级（班级的属性，管理员维护；只有管理员能按院系、年级发布） |
| R3 | 作业分数以老师确认为准；AI 分只是建议，只给老师看 |
| R4 | 截止后还能交，标逾期，不自动扣分 |
| R5 | 学生自建的内容不能分享给同学 |
| R6 | 学生能看到全班平均分，不显示排名 |
| R7 | 先不做全校统计看板 |
| R8 | 精通之路及格线：严格 90%、标准 80%、宽松 60%；目前只影响打分类知识点 |
| R9 | 老师改精通之路档位后，发布更新才对学生生效 |
| R10 | 「截止后显示答案」的练习集，截止前不显示分数和对错；答案显示过以后，截止时间不能再往后改 |
| R11 | 精通之路首次发布：勾了学生就只发给勾的人；没勾就按第 4 节处理 |
| R12 | 练习集发给「全部」时，老师成绩表只列自己班的学生和单独指定的人 |
| R13 | 管理员对别人的内容、任务只能撤回，不能加人、移人、改范围、改内容 |
| R14 | 范围数据丢失时一律不放行，恢复后才能继续发布 |
| R15 | 最好成绩按得分率挑，和它那个版本的满分一起显示 |
| R16 | 管理员发布的内容在学生那边叫「学校发布」 |
| R17 | 退班学生的历史成绩不另做处理：发给班级的练习集，退班的人仍留在成绩表里，标「不在范围内」；发给「全部」的，退班后不再出现 |
| R18 | 通知只在站内，不接微信，也不接邮件 |
| R19 | 发布过的内容和任务只能撤回，不能删除；只有作者能删从没发布过的 |
| R20 | 老师被删除或改成学生时：内容、任务、课程转给执行操作的管理员；有作业的任务优先转给所发班级的另一位任课老师 |
| R21 | 作业只属于老师和学生，管理员看不到，也不能布置带作业的任务 |
| R22 | 精通之路、练习集、课程、任务只发给学生；带作业的任务不能发给「全部」 |
| R23 | 同一个学生、同一个任务只算一条；内容被任务引用后，不再自动生成任务 |
| R24 | 「已完成」永久保留；「已关闭」按当前是否在范围内实时算，回到范围就恢复 |
| R25 | 课程的顺序只是建议，不上锁 |

## 11. 不做的

- 学科、专业、教研组等更多组织层级（院系、年级已于 2026-11-03 加入，见第 2 批设计第 0 节）。
- 院系管理员。
- 微信、邮件通知。
- 「问老师」答疑：学生的疑问由 AI（聊天和「小老师」）解答（2026-11-02 确认）。
- 同学之间讨论、学习小组、排行榜。
- 学生之间分享自建内容。
- 全校统计看板。
- 家长（监护人）功能。
- 给个别学生单独延期：老师可以改整个任务的截止时间。

## 13. 分批实施

| 批次 | 内容 | 做完能走通的流程 |
|---|---|---|
| 第 0 批 | 第 9 节 4 条修复；第 3 节来源统一；管理员能撤回别人的练习集；老师改成学生时转交内容 | 发给谁、从哪来，处处清楚；账号变化不留尾巴 |
| 第 1 批 | 任务（5.4）、作业（5.5）、通知（5.8）、学生首页和历史、看板的「老师布置」列，以及第 6 节里和这些有关的联动 | 老师布置 → 学生收到通知 → 完成或交作业 → 老师批改或退回 → 学生看到结果 |
| 第 2 批 | 点评（5.6）、公告（5.7）、老师课程（5.10）、开放时间和日历，以及对应的联动 | 老师按课程带学，并对学生给出点评 |
| 第 3 批 | 补练（5.9）、用书出题、老师工作台和「需要关注」、第 8 节各项、学生权限按班设置、学生导航精简、AI 用量上限、注册防刷 | 从报告发现问题 → 生成补练 → 学生练 → 再看报告 |

每一批都按同样的步骤走：先写详细设计，确认后实施，然后跑全量测试、在浏览器里实测，最后在本地提交。

## 14. 实施约定

- 新功能放在新的独立模块里，例如 `deeptutor/tasks/`、`deeptutor/notifications/`。已有文件里只加最少的接入点。
- 新的系统库沿用现有约定：只有写入时才建库，读取时不建任何文件，读不出来时一律不放行。
- 学生的对话、笔记、自建内容、题库，不搬进系统库。只有交给老师的作业才进系统库，并且只给对应的老师看。
- 第 6 节表格里的每一格，都要有对应的测试。
- 界面文字六种语言同步。
