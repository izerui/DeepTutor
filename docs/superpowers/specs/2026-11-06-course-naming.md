# 课程相关叫法（2026-11-06，方案三）

> 状态：用户选定方案三（2026-11-06）。只改界面文字，不动数据、接口、路由。

| 位置 | 新叫法（中文） | 英文 |
|---|---|---|
| 侧栏入口（市场上的课程，`/tasks`） | 我的课程 | My courses |
| 页面两栏 | 在学 / 创作 | Learning / Created |
| 课程里的一项 | 课时 | lesson（英文不变） |
| 个人学习空间里的「课程」（`/courses`，按一个科目整理资料、大纲、对话） | 科目（书架标题「我的科目」） | Subject（书架 My subjects） |
| 聊天里的选择器 | 科目：考研数学 | Subject: … |

- 市场、内容介绍页、学习报告、通知里说的「课程」仍指市场上的课程。
- 个人「科目」相关的所有文字（新建、编辑、大纲、资料、进度、聊天选择器、空状态）都从「课程」改为「科目」。
- 其他语言跟着英文改：德 Fach / Meine Fächer，法 matière / Mes matières，波兰 przedmiot / Moje przedmioty，乌克兰 предмет / Мої предмети；课时在德法波乌沿用 lesson 的现有译法。
- 市场分类里的「学科」（taxonomy）不变。
