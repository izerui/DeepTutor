# 删除老师管理学生的功能（2026-11-05）

> 状态：用户同意（2026-11-05）。接着「删除作业」：平台是学习平台（类似慕课），学习者自己加入、自己安排节奏；老师不点评个人、不点名发内容、不盯人、不设截止。用户选定删除下面四项。作者公告、学习报告、练习集改分、管理员转交本批不动。

## 1. 删掉的

### 1.1 老师点评学生
- 后端：`deeptutor/comments/` 整个模块（练习答卷点评、精通之路知识点点评），接口 `/api/comments`，账号删除交接里的 `comments` 一步，通知 `teacher_comment`。
- 前端：`components/comments/`，练习集答卷和学习报告里的点评编辑框，学生侧看点评的地方，通知文字。

### 1.2 点名发内容
- 老师补练：从练习集或精通之路的错题给选中的学习者生成补练并发给他们（`POST /api/practice-sets/remedial/from-set`、`/remedial/from-path`，`practice_sets/remedial.py`）。学生自己用错题生成相似题（`/api/remedial/similar`）保留。
- 精通之路手动加人、移除人：`POST/DELETE /api/mastery-teaching/templates/{id}/assignments…`、`GET …/students`，`path_added_students`、`path_revoke_allowed`。路线只给加入的人。
- 发布时指定发给谁：发布接口里的 `scope.users`、改发布范围里的点名、课程发布时把点名带给任务（`chosen_scope`）。发布后只有加入的人能收到。
- 「老师的学习者」（`learners_of`）只剩这些地方用，一并删掉。
- 前端：补练对话框、精通之路「管理学员」对话框、发布时选人的控件。

### 1.3 需要关注
- 后端：`catalog/attention.py`；工作台的 `attention` / `attention_total`；学习报告每行的 `flags` 和 CSV 的 `attention` 列。
- 前端：工作台「需要关注的学习者」、学习报告里的关注标记、`attention-format.ts`。

### 1.4 截止时间、开放时间、日历
- 任务：不再设 `due_at` / `open_at`；去掉「逾期」「未开放」状态、迟交标记，通知 `task_due_soon`、`task_opened`、`task_due_changed`，以及看通知时顺带发提醒的 `sweep`；任务发布通知里不再带截止时间。
- 练习集：不再设截止时间；「截止后公布答案」去掉，只剩「提交后公布答案」；去掉市场里「练习不能有截止时间」的检查和提示。
- 日历：接口 `/api/tasks/calendar`、页面 `/calendar`、侧栏入口。
- 前端：任务和练习集编辑里的时间输入、学生侧的截止/逾期/未开放显示、日历页、三种通知文字。

## 2. 已有数据
- 不做数据迁移，库表的列保留不用：
  - 任务、练习集上已有的截止时间、开放时间一律不再读取；
  - 设成「截止后公布答案」的练习集按「提交后公布答案」处理；
  - 以前点名发给某些人的内容，这些人照样能看到（和以前「所有人可见」的旧数据一样，只读不再新增）。
- 点评、补练、通知这些新功能生产上没有数据，不清理。

## 3. 验证
- 后端全量测试通过（退出码 0），14 个回环测试通过。删掉只测这四项的测试；原来靠点名或手动分配准备数据的测试改成「加入」（新增 `tests/multi_user/path_members.py`）。新增 `tests/multi_user/test_no_teacher_management.py`：发布时点名被拒、分配学员接口已删、时间字段被拒、旧的「截止后公布答案」提交后即可看答案、旧任务有过期截止时间也只是「待完成」、旧的点名范围仍能读到。
- 请求里多传 `due_at`、`open_at`、`student_ids`、非空 `scope.users` 一律 422。
- 前端：类型检查 0 错误，vitest 1099 个、node 测试 1370 个通过，六种语言检查、契约检查通过。精通之路的「管理学员」对话框去掉学员部分，剩下的上架、报告、公告、归档改名为「管理路线」。发布选人的三个组件和前端的发布范围接口一并删除。
- 浏览器：老师侧栏没有日历、`/calendar` 是 404；工作台没有「需要关注」；练习集编辑没有截止时间和公布答案设置，成绩查看里没有点评和补练；任务编辑没有时间；学生任务页没有截止和逾期，练习集正常显示成绩。
