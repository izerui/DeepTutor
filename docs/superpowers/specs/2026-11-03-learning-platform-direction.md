# 调整方向：从「老师带班」到「学习平台」——整体设计

> 日期：2026-11-03
> 状态：已确认（2026-11-03），第 11 节 4 条按建议执行。按第 10 节分批实施，每批再出详细设计。
> 关联：`2026-11-02-teaching-direction-roadmap.md`（第 0～4 批的总体方案）。本文不推倒重来：已做好的功能尽量保留，按新方向改挂；冲突处以本文为准。

---

## 1. 方向

- 平台上有很多书、知识库、精通之路、练习集、课程，由老师（创作者）和管理员上架。
- 任何人都可以在「学习市场」里挑自己想学的，点「加入学习」后开始学。不按班级、年级圈人：学计算机的人也可以学数学。
- 学生照旧可以自建精通之路、书、知识库、课程，自己用，但不能上架。
- 班级不再是组织方式。原来挂在班级上的任务、作业、批改、点评、公告、报告，改成面向「加入了这门课程或这条精通之路的学习者」（慕课式）。

## 2. 角色和权限

| 能力 | 管理员 | 老师（创作者） | 学生 |
|---|---|---|---|
| 系统配置、账号、学生权限、分类和标签 | ✓ | | |
| 创建内容 | ✓ | ✓ | ✓（自己用） |
| 上架到平台 | ✓（直接上架） | ✓（第一次要审核） | |
| 审核老师的上架申请 | ✓ | | |
| 下架自己的内容 | ✓ | ✓ | |
| 撤回别人已上架的内容（兜底） | ✓ | | |
| 改别人内容的分类、标签（纠错，不改内容） | ✓ | | |
| 在市场里浏览、加入学习 | ✓ | ✓ | ✓ |
| 给自己课程的作业批改、点评，发课程公告，看课程报告 | | ✓ | |

- 老师和管理员自己也是学习者，也能加入别人的内容。
- 学生自建内容的开关（按人设置）保留；「按班设置」这一层去掉（见 8.4）。
- 作业仍只属于交作业的人和课程作者，管理员看不到（R21 不变）。

## 3. 上架和审核

### 3.1 状态

```
未上架 ──提交──▶ 待审核 ──通过──▶ 已上架
                  │                 │  ▲
                  └─驳回(写原因)─▶ 已驳回 ─改后再提交─▶ 待审核
已上架 ──作者下架──▶ 已下架 ──作者重新上架（不用再审）──▶ 已上架
已上架 ──管理员撤回(写原因)──▶ 已撤回 ──作者改后再提交──▶ 待审核
```

| 规则 | 说明 |
|---|---|
| 老师第一次上架 | 进「待审核」，通过后才出现在市场 |
| 管理员上架 | 直接「已上架」 |
| 驳回 | 必须写原因，作者收到通知，改完可以再提交 |
| 已上架后改内容 | 不再审核，直接生效（版本规则见第 4 节） |
| 作者下架 | 从市场消失，不能再加入；已经加入的人继续学 |
| 作者重新上架 | 审核通过过的，直接回到「已上架」 |
| 管理员撤回 | 写原因，作者收到通知。已加入的人也打不开了，显示「内容已不可用」，各自的学习记录保留。作者要再上架，必须重新审核 |
| 作者归档、设为私有（原有功能） | 保持现状：所有人都不能再进；上架记录变成「已下架」 |

- 审核通知只在站内：有新申请时管理员收到；通过、驳回、撤回时作者收到。
- 管理员审核时能只读地打开这份内容（书看目录和正文，精通之路看大纲，练习集看题目，课程看条目）。

### 3.2 上架时要填的

| 字段 | 要求 |
|---|---|
| 标题、简介 | 默认取内容本身的名称和描述，可以改 |
| 学段 | 必选，1～3 个，只能从预置分类里选 |
| 学科 | 必选，1～3 个，必须属于所选学段，可以选到二级 |
| 难度 | 必选 1 个：入门 / 初级 / 中级 / 高级 |
| 标签 | 可选，最多 8 个，作者自由填写 |

- 能上架的前提：书有正文，知识库有文档，精通之路已发布过一版，练习集已发布且有题，课程至少有一项。
- 学生账号看不到「上架」按钮，后端也拒绝。

## 4. 版本规则

上架后改内容一律不审核、直接生效。各类内容的现状和对齐方式：

| 内容 | 现状 | 改了以后 |
|---|---|---|
| 精通之路 | 每次发布生成固定修订版；学习者的副本记着用的是第几版，升级时迁移，进度不丢 | 保留现状：作者发布新版即生效，学习者下次打开换成新版 |
| 练习集 | 每次发布生成固定版本；每次作答记着版本 | 保留现状：发布新版即生效；交过的作答按当时的版本保留 |
| 书 | 没有版本，改了立即生效；阅读进度存在学习者自己那边 | 保留现状：改了立即生效。市场里显示「更新于 X 日」 |
| 知识库 | 文档有版本（给精通之路锁定引用用），知识库本身改了立即生效 | 保留现状 |
| 课程 | 没有版本，增删条目立即生效 | 保留现状：新加的任务直接到达已加入的人 |

- 结论：有版本的（精通之路、练习集）按版本走，没版本的（书、知识库、课程）改了就生效，都不审。不给书、知识库、课程新加版本，没有必要。
- 标题、简介、分类、标签随时可改，立即生效。

## 5. 学习市场

### 5.1 浏览和筛选

- 像京东一样：左边（或顶部）是筛选条件，右边是结果。
- 条件：学段、学科（可展开到二级）、内容类型、难度、标签、作者。
- 同一条件里多选是「或」，不同条件之间是「且」。每个选项旁边显示符合的数量，选中的条件在结果上方列出，可以单个去掉或一键清空。
- 关键词搜索：匹配标题、简介、标签、作者名。
- 排序：最新上架、最多人学。
- 每张卡片：类型、标题、作者、学段和学科、难度、加入人数、是否已加入。
- 学科没填的旧内容（见 9.1）能被关键词搜到、能在「全部」里看到，但不出现在学段、学科筛选里。

### 5.2 内容介绍页

- 标题、简介、作者（点进作者主页）、分类、难度、标签、加入人数、更新时间。
- 内容预览：书看目录，精通之路看模块和知识点，练习集看题量和题型（不露题目），课程看条目列表，知识库看文档列表。
- 按钮：「加入学习」/「继续学习」/「退出学习」。

### 5.3 作者主页

- 作者名字、上架的全部内容（按类型分组）、每项的加入人数、总加入人数。
- 评分、评论、收藏以后再做。

## 6. 预置分类

上线就自带，管理员只在上面调整：改名、隐藏、排序、加新项。已有内容在用的项不能删，只能隐藏（隐藏后不出现在筛选和上架选项里，已有内容保留原分类）。

### 6.1 学段（层次）

小学、初中、高中、大学、考研、职业技能、兴趣与生活

### 6.2 学科

参考中国大学 MOOC、学堂在线：中小学按课程科目（只有一级）；大学按学科门类（一级）和专业类（二级），另加「公共基础课」。完整清单见附录 A。

| 学段 | 一级 | 二级 |
|---|---|---|
| 小学 | 语文、数学、英语、科学、道德与法治、信息科技、音乐、美术、体育与健康、劳动 | — |
| 初中 | 语文、数学、英语、物理、化学、生物学、历史、地理、道德与法治、信息科技、音乐、美术、体育与健康 | — |
| 高中 | 语文、数学、英语、物理、化学、生物学、历史、地理、思想政治、信息技术、通用技术、音乐、美术、体育与健康 | — |
| 大学 | 公共基础课 + 12 个学科门类 | 公共基础课的科目；各门类下的专业类 |
| 考研 | 公共课、专业课 | 公共课：政治、英语一、英语二、数学一、数学二、数学三、管理类联考综合、经济类联考综合；专业课：按 12 个学科门类 |
| 职业技能 | IT 与互联网、职业资格证书、办公效率、设计创作、经营管理、市场营销 | 见附录 A |
| 兴趣与生活 | 外语、文学阅读、历史人文、艺术欣赏、音乐、书画摄影、健康运动、心理成长、科普、理财 | — |

### 6.3 难度

入门、初级、中级、高级

### 6.4 标签

- 作者上架时自由填写，系统自动去掉首尾空格、统一大小写。
- 管理员可以把同义标签合并（比如「Python」「python3」→「Python」）：所有内容上的旧标签换成新标签，以后有人再填旧标签，自动换成新标签。

### 6.5 原来的院系、年级要不要改成分类

**不改。** 院系、年级描述的是某所学校里的人怎么分组（「计算机学院」「2023 级」），不是内容讲什么。内容分类用上面这套预置分类就够了。原有的院系、年级数据保留，界面撤掉（见第 8 节）。中小学内容如果需要按年级区分（比如「七年级上册」），先用标签；以后有需要再给中小学加一个可选的「年级」条件。

## 7. 加入学习

- 市场里点「加入学习」，内容进入自己的学习列表（精通之路、书、知识库、练习集、课程各自的列表里），来源标为「平台 · 作者名」（管理员的仍显示「学校发布」，可以改叫法，见第 11 节）。
- 不再自动推给任何人。
- 加入后各类内容怎么用：
  - 精通之路：生成自己的学习副本（沿用现有的分配和副本机制），按第 4 节跟随新版。
  - 练习集：可以作答；分数记给作者看（作者只看自己内容上的成绩，规则不变）。
  - 课程：收到课程里的全部任务，任务引用的精通之路、练习集、书、知识库一并能用，不用再逐个加入。
  - 书、知识库：出现在自己的列表和聊天的资料选择里。没加入的已上架书，也能在介绍页预览目录。
- 退出学习：从列表里移除，学习记录保留；再次加入接着学。
- 加入人数 = 当前已加入、没退出的人数。

### 7.1 课程里能引用什么

- 原来要求「被引用内容的发布范围覆盖课程的全部接收者」，改成：课程只能引用已上架的内容，或者作者自己的内容（没上架的也行，只经这门课能用）。
- 精通之路引用的书、知识库同理：已上架的，或作者自己的（沿用现有「经路线能用、打不开资料本身」的规则）。

## 8. 班级相关功能怎么改挂

### 8.1 去掉班级

- 从界面上撤掉：班级页和侧栏入口、院系年级管理、邀请进班（链接、二维码、邀请）、任课老师、按班设置学生权限、发布时选班选人（「发给谁」）。
- 代码和数据先保留，不删。
- 注册：不再带进班邀请。开放注册时自己注册；关闭时只能由管理员建号。
- 老师不能再重置学生密码（原来是「本班学生」），只有管理员能。

### 8.2 改挂到课程和精通之路

| 原来 | 改成 |
|---|---|
| 任务发给班级 | 任务只放在课程里；加入课程的人收到。不再单独发任务 |
| 作业：本班学生交，任课老师批改 | 课程学习者交，课程作者批改、退回、点评（批改流程本身不变） |
| 班级公告 | 课程公告：发给这门课的学习者；精通之路作者也可以给这条路线的学习者发 |
| 老师点评 | 不变：练习作答由练习集作者点评；精通之路卡住的知识点由路线作者点评（条件从「被分配」改成「已加入」） |
| 班级报告 | 课程报告、精通之路报告：看这门课或这条路线的学习者整体数据和每个人的进度 |
| 需要关注的学生 | 范围从「我班上的学生」改成「我的课程和路线的学习者」，只在对应报告里显示 |
| 补练（老师端） | 从课程或路线报告里生成，作为一项加进这门课，或单独上架 |
| 全班平均分 | 改叫「学习者平均分」：所有交过的人，规则不变（至少 3 人） |
| 老师工作台「我的班」 | 改成「我上架的内容」：审核状态、加入人数、待批改 |
| 资料被撤回通知 | 判断条件从「接收者看不到了」改成「被引用的资料下架或被撤回了」 |
| 老师离开时转交 | 不变：内容转给管理员；有作业的任务原来优先转给同班老师，改成直接转给管理员 |

### 8.3 任务和课程的关系

- 任务都属于某门课程。原来单独发出去的任务，迁移时照旧对已收到的人有效（见 9.2），之后不能再新建单独的任务。
- 老师发出的练习集、精通之路原来会自动显示成任务。改成：加入后出现在自己的学习列表里，不再自动变成任务。

### 8.4 学生权限

- 只剩「个人设置」和「默认」两层，去掉班级层。
- AI 每日用量：个人设置优先，没有就用默认（原来中间还有「各班最宽的那个」）。

## 9. 旧数据怎么处理

原则：上线新方向时，谁都不丢已经在学的东西。

### 9.1 用「全部」范围发布的

- 视为已审核，直接「已上架」，记录为系统迁移。
- 已经动过的人自动算「已加入」：精通之路答过题、练习集交过、课程完成过任务、书有阅读进度。没动过的人不算加入，原来自动推给他们的那份从列表里撤下（自己什么都没做，不丢东西）。
- 学段、学科都空着。作者和管理员在工作台看到「待补分类」的提示，补填后才出现在学段、学科筛选里（关键词搜索和「全部」里一直能看到）。

### 9.2 发给指定班级、院系年级、个人的

- 不上架，状态是「未上架」。作者可以去申请上架。
- 迁移那一刻能收到它的人，全部算「已加入」（这些是老师有意发给他们的），之后不再随班级变化。

### 9.3 其他

| 旧数据 | 处理 |
|---|---|
| 学生以前公开过的书、知识库 | 不进市场，保持现状只读，以后再定是否收回 |
| 单独发的任务 | 已收到的人照旧有效（固定成个人名单），之后不再新建 |
| 班级权限设置 | 每个学生按迁移时的实际结果，凡是班级层改变了的项，写进他的个人设置，权限不变 |
| 班级的 AI 用量上限 | 同上，写进个人设置 |
| 班级公告 | 保留在库里，界面不再显示 |
| 班级、院系、年级、邀请 | 保留在库里，界面撤掉 |

迁移只跑一次，可重复运行不出错，跑之前自动备份相关的库。

## 10. 分批实施

| 批次 | 内容 | 做完能走通的流程 |
|---|---|---|
| 第 1 批 | 预置分类（先只读）；上架、审核、驳回、下架、撤回；学习市场（筛选、搜索、排序）、内容介绍页、作者主页、加入人数；加入学习和退出；五类内容的发布对话框把「发给谁」换成「上架」；9.1 的迁移 | 老师上架 → 管理员审核 → 学习者在市场里筛选找到 → 加入学习 → 在自己的列表里学 |
| 第 2 批 | 去班级：撤入口和「发给谁」；9.2、9.3 的迁移；学生权限去班级层；注册去邀请；任务只在课程里；老师工作台改版；管理员的分类管理和标签合并 | 界面上不再有班级，旧学生的东西都在 |
| 第 3 批 | 课程和精通之路的学习者：作业批改和点评、课程公告、课程和路线报告、需要关注、补练、学习者平均分、资料下架通知、转交规则 | 老师按课程带学习者：布置作业 → 批改点评 → 看报告 → 补练 |

每一批照旧：先出详细设计，确认后实施，跑全量测试，在浏览器里实测，最后在本地提交，不推送。

## 11. 需要你定的

1. **管理员上架的内容怎么标来源？** 建议从「学校发布」改成「平台发布」，因为不再以学校为单位。
2. **管理员能不能改别人内容的分类和标签？** 建议能（只为纠错、合并标签），第 2 节已按「能」写。
3. **没加入的人能不能直接看书的正文？** 建议不能，只能预览目录；加入后才能读。
4. **上架的练习集还要不要「截止时间」？** 市场里的练习集是随时学的，建议截止时间只在课程任务里设，上架的练习集不带截止时间。
