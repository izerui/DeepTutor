# 只有管理员和学习者两种角色（2026-11-05）

> 状态：用户同意（2026-11-05）。用户原话：「这个作者和这个学生其实就是一个角色……他学别人的东西，他是学生，别人学他的，那他就是作者」「学习报告……汇总查看学情……仅限于管理员和这个作者去看」。

## 1. 角色
- **管理员**：管平台。审核上架、下架内容、管分类和标签、管账号、设 AI 每日用量。
- **学习者**：除管理员外的所有人。既能在市场里加入别人的内容来学，也能自己做课程、精通之路、练习集、书、知识库并申请上架。
- 「作者」不是角色，是对某个内容而言：谁做的谁就是它的作者。
- 「老师」「学生」两种角色取消。

## 2. 规则怎么变
- **创作和上架**：原来只有老师和管理员能做的（建课程和任务、建练习集、发布精通之路给别人学、申请上架、发公告、看学习报告）对所有学习者开放。首次上架仍要管理员审核，管理员仍可下架。
- **学习报告**：作者和管理员都能看，只读，不能改学习者的任何东西。内容是加入者的进度、完成情况、作答汇总，能导出。其他人看不到。（原来管理员不能看，这里放开。）
- **功能开关取消**：个人精通之路、书、私有知识库、个人课程、任务卡、伙伴、智能体、协作写作，所有人都能用；管理员后台的「学生权限」设置和个人权限设置一并删除。
- **AI 每日用量**：保留，作为管理员控制成本的手段，对所有学习者生效（全站默认 + 个人设置，默认不限）；管理员不受限。
- **工作台**：原来只有老师有，改成每个人首页都有「我发布的」「我上架的」「我在学的」。
- **账号管理**：管理员建账号或改角色时只有「管理员 / 学习者」两种；注册来的账号是学习者。
- 界面文字里的「老师」「学生」改成「作者」「学习者」。

## 3. 已有账号
- 不改库里存的角色值：老师、学生、旧的 user 账号读出来都当学习者，管理员还是管理员。学习者在库里沿用 `student` 这个值，以后新建和改角色只写 `admin` 或 `student`；接口和界面上称「学习者」。
- 已有的功能开关设置不再读取（库里留着不用）。已有的个人 AI 用量设置照旧生效，开始也对原来的老师账号生效；全站默认不限，所以没设过的人不受影响。

## 4. 不变的
- 市场、上架审核、加入和退出、评分收藏、作者公告、学习者自己用错题生成相似题。
- 管理员转交课程或任务：保留，接手人从「在职老师」改为「任一在用的学习者」。
- 改角色不交接内容：学习者改成管理员、管理员改回学习者，做过的内容都还是自己的（管理员也能当作者）。
- 账号删除时交接：被删账号做过的内容交给接手人，对所有人适用。

## 5. 用户的决定
- 功能所有人都能用，不再按角色或开关限制（2026-11-05）。
- 学习报告管理员和作者一样能看每个人的明细（只读）。

## 6. 验证
- 后端全量测试：只有两处断言因措辞改动失败（「学生」改「学习者」、「拥有路线的老师」改「路线的作者」），已更新并通过；14 个回环测试通过。新增 `tests/multi_user/test_one_learner_role.py`。
- 前端：类型检查 0 错误，vitest 1097 个、node 测试 1370 个通过，六种语言检查、契约检查通过。
- 浏览器：原来的学生账号首页有「我发布的」「我上架的」「我在学的」，能建练习集、发布并看到上架面板；管理员的账号管理里角色只有「管理员 / 学习者」，没有学生权限开关，保留每日 AI 用量；管理员能打开别人课程的学习报告，其他学习者打不开（404）。
- 已知未做：管理员在课程学习报告里看到的练习集只显示标题，点不开练习集成绩（作者在自己的练习集编辑页里看）。
