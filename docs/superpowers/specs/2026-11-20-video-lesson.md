# 视频讲解课（从上游借鉴，2026-11-20）

> 状态：用户确认（2026-11-20）。用户同意下一个做视频课（「好」）。调研见 `.superpowers/video-lesson-survey.md`。

## 1. 是什么

在聊天里选「视频讲解」，说一个主题，AI 生成一段 1～2 分钟、带字幕和旁白的讲解动画，在浏览器里直接播放。

- 做法（照上游）：模型按内置组件库写一段动画代码 → 服务器编译、在隔离的解释器里试渲染若干帧 → 出错就把错误交回模型重写（最多几轮）→ 生成一个自带播放器、字幕和配音的页面。服务器不生成 mp4。
- 配音：先用管理员配置的朗读服务，失败用免费的 Edge 语音，都不行就只放字幕。
- 名字：叫「视频讲解」（英文 Video Lesson）。我们已有的「视频学习」（看网络视频、记时间点笔记）是另一个功能，不动、不改名。

## 2. 谁能用、怎么管

- 所有学习者都能用（和其他 AI 功能一样），算进每人的 AI 每日用量。
- 生成一次可能用掉十万级 token，所以管理员可以设：
  - 学习者能不能用视频讲解（默认能）；
  - 单次写稿的 token 上限和最多重写几轮（默认比上游低：写稿上限 24000、最多 3 轮；上游是 48000、4 轮）。
- 运行环境（Node、npm 镜像、运行状态检查）只在管理员设置里出现，学习者看不到。

## 3. 运行环境

- 需要服务器有 Node.js 22 和 npm；第一次使用时自动安装固定版本的渲染包。
- 渲染包装在全站共享目录（`system/` 下），所有用户共用一份，安装时加锁，避免多人同时首次使用时重复安装。上游是每个用户各装一份。
- 没有 Node 时：视频讲解显示「服务器未安装运行环境，请联系管理员」，其他功能不受影响。
- Docker 镜像加装 Node 22（如果镜像里还没有）。

## 4. 布局检查（画面元素重叠检查）

- 上游会用无头 Chrome 打开生成的页面，检查文字重叠、出画、挡字幕，有问题再让模型修。
- 这一步是在服务器的浏览器里打开模型写的页面，有安全风险。本批：**默认关闭**，管理员可以在设置里打开；打开时页面在只允许脚本的隔离环境里加载，禁止联网。没有 Chrome 时自动跳过。

## 5. 结果保存和查看

- 生成的页面存在用户自己的工作区里（和其他聊天产物一样），只有本人能打开。
- 播放用只允许脚本的 iframe，服务端加内容安全限制。
- 重新打开对话时能再次播放。

## 6. 放进书、课程和市场（最后一批）

- 生成的视频讲解可以「插入到书」：成为书里的一种内容块，跟着书一起分享、上架。
- 课程里用现有的「书」类课时指向那一章，学习者在课程里就能看到视频讲解。
- 上架的书里，加入的学习者能播放作者生成的视频讲解（需要把产物随书一起发布，而不是指向作者的私人文件）。
- 同时查一下书里现有的「动画」块，是否也有「学习者打不开作者文件」的问题，有就一起修。

## 7. 分批

1. 运行环境和隔离：共享安装目录、加锁、Node 检测；隔离解释器脚本；取消时清理进程树的修复。
2. 写稿、配音、注册成聊天能力、保存结果；算进 AI 用量；管理员开关和 token 上限。
3. 布局检查（默认关闭）和安全限制。
4. 前端：聊天里选「视频讲解」、进度显示、播放器；管理员设置页的运行环境和开关；6 种语言。
5. 插入书、随书发布、课程和市场里能看。

每批：全量测试 → 本地提交。全部做完后在浏览器里实测（需要可用的模型密钥；没有的话先用测试替身走通流程，等有密钥再补实测）。

## 8. 不做

- 生成 mp4、下载视频文件。
- 用知识库、附件做视频讲解的素材（上游也不支持，以后可以加）。
- 时长、分辨率可调（固定 1～2 分钟、1920×1080）。

## 9. 实际结果
- 5 批分别提交：8bd44a553、ba9471d5d、e54a2086f、c92d83037、be6c3deda。
- 后端全量 14840 个用例，只有 5 个已知 mineru `/bin/ps` 沙箱失败；回环 22 个通过；前端类型检查、vitest 1566 个、node 测试 1439 个、语言检查、契约检查通过。
- 本机 Node 22 上用固定写稿走真实编译和渲染，生成可播放的页面，浏览器带服务端安全限制打开正常。
- 浏览器：管理员设置里有「视频讲解」页（学习者能否使用、token 上限、最多轮数、布局检查、运行状态、立即安装、npm 镜像）；聊天的模式菜单里有「视频讲解」。
- 未实测：用真实模型生成（开发数据里的模型密钥都被服务商拒绝）。
- 与方案的差别：
  - 布局检查为能运行关掉了 Chrome 的 `IsolateSandboxedIframes`，页面仍在只允许脚本的隔离框里、Chrome 断网。
  - 「立即安装」是同步请求，最长约 15 分钟。
  - 书里原有的「动画」块确有学习者打不开作者文件的问题，已改为随书发布；管理员在别人书上生成的旧动画仍需重新生成。
  - 删除视频讲解块后，书目录里的文件不删，只是不再提供。
